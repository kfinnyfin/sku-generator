Standard Prices

One flat default MSRP per product, independent of size, print hits, and MFA cost. Changes apply to new brand forms only and never rewrite already-saved brand pricing.

These prices are used as the starting MSRP for newly-generated brands.

Garment SKU codes

Edit the garment code used in generated SKUs. Enter the base code only, such as C1717. The print method adds -FTG automatically.

Shared across devices. Existing saved catalogs keep their SKUs until you edit and save each brand again.

Admin

Standard Print Methods

Set the normal DTG or FTG method for each product once it is confirmed. “Not set” remains allowed here, but every selected product must have a method before a brand can be saved or exported.

These defaults prefill new brand forms. Every product can still be overridden inside a brand.

Color Guide

Colors are shown by their full names throughout the app. Generated SKUs format multi-word colors with underscores automatically.
